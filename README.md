# POS downloads

Installers and phone app releases for the POS system. The source code is private; this
repository only holds the release files.

- `POS-Setup-<version>.exe`: the shop laptop (Windows). Installs the shop server and the
  desktop till. Installed laptops update themselves from here.
- `pos-till.apk`: the phone till (Android). Phones normally update from the shop laptop.

Updates are signed: the app only installs files signed with the publisher's update key.
